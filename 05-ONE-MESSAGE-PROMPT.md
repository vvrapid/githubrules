# 05 — One Message for Any AI Developer

**Copy exactly this message into the AI developer/controller session for a new or existing application:**

> Adopt the universal development standards from the private GitHub repository **https://github.com/vvrapid/githubrules**. With authorised access, read its **README.md** and then files **01 → 04 in order**; follow its **05-ONE-MESSAGE-PROMPT.md** as the usage guide. Pin the source commit/version; inspect this application's existing code, agent instructions, tests, GitHub Actions, branch protections and permissions. Integrate the speed-first, risk-based controller policy **without overwriting existing safeguards or adding bureaucracy**. Create only necessary compact local references and project-specific configuration; reuse existing controller/task systems. Optimise unnecessary GitHub minutes and AI tokens, using stack-specific verified CI rather than copied generic YAML. Delegate independent work if supported and helpful, preserve spending/production approval limits, and **continue implementing the application's existing priorities immediately**. Do not claim success where repository access or checks are unavailable. Briefly report what you installed, source commit, exceptions, validation and next active task.

## Notes for project owner
- The developer needs **authorised read access** to private `vvrapid/githubrules` and edit access to the **target** application if you expect it to change files. Merely sending the URL does not grant private access.
- It does **not** automatically deploy, purchase minutes, merge to protected branches or change billing.
- For future projects, reuse the same message. The developer should detect the application and fill its actual configuration; you should not have to repaste the long policy.
